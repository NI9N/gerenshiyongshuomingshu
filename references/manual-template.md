# 《个人使用说明书》模板

用法:教练收尾时,把全程产物填进下面的结构,生成一份完整、自包含的 Markdown 说明书。方向性结论一律用"假设/目前最值得下注"措辞。
**每个章节标题下都标注状态**:`截至日期 · 类型:事实(有行为证据)/ 我的解释(自述)/ 待验证假设`。类型不标 = 读者会把它当"你就是这样",这正是本模板要防的。

> 隐私说明:下面"一、填好的样子"用的是**虚构人物**,为避免把真实个人档案装进可分发文件。跑你自己的走查时,产出的说明书请自己私有保存。

# 一、填好的样子(示例 · 虚构人物)

# 个人使用说明书 —— 阿澈(虚构示例,不是真人档案)

> 生成日期:2026-09-05(示例用) · 状态:第一版 · 一句话定位:**我是一台"带新手少摔跤的引路人"——不替你爬,但帮你把路看清。**

## 1. 使用目的(待验证假设)
> 为了帮第一次进山的人少走弯路、安全下山,我用"把复杂路线拆成新手能懂的分段 + 耐心带教"的方式,做户外徒步入门的内容和领队产品。

- 验证问题 1:如果开一条"新手夜爬体验线",会有人报名吗?(问 3 个不太熟的人 + 发一条朋友圈看反馈)
- 验证问题 2:两周内带 2 个真新手走一次短线,能收到"下次还跟你"吗?
- 验证问题 3:三个月后我还想继续,还是只是"想当领队很酷"?

## 2. 功能与擅长(才能清单 · 自评,非测量)
| 长处 | 标记 |
|---|---|
| 路线规划、把步骤拆成小段讲给新手 | ◎ |
| 环境观察、风险预判(看天气/地形) | ◎ |
| 耐心讲解、不嫌问题蠢 | ◎ |
| 组织小团队、照顾队尾 | ◎ |
| 拍照记录、回来写复盘 | ○ |
| 快速查攻略、辨别信息真假 | ○ |

◎=自评回血+出成果;○=自评回血。**以上全部是本次对话的自评,不是测量;用真实带线记录核过后再升格为"事实"。**

## 3. 电源与能耗
> 截至 2026-09-05(示例)· 类型:我的解释(待行为记录核对)
- 充电:带新手走通一条线、被人问"下次什么时候"、研究一条新路线、下山后写复盘。
- 耗电:机械改图、被当免费司机、大公司流程扯皮、无反馈的重复劳动。
- 规律:帮一个具体的人"少摔一跤"并被他看见 → 满电;只是被夸"领队好帅" → 很快见底。

## 4. 设计哲学(人格底色 + 价值观链 · 当前解释)
- 底色:**引路人型**(更享受"带人走通"而非自己冲顶)。证据:过去半年每个周末免费带同城网友爬短线,没人付钱也去。
- 价值观链(地基→目的):真实不装 → 把安全与常识讲透 → 不落下队尾的人 → **让新手也能放心进山**。
- 底线:最怕变成"为了流量带人去危险路线"的人。

## 5. 使用禁忌(什么会卡住我 · 截至本日,可修订)
- 被要求"顺便帮我涨粉/带带货"式的工具化。
- 无反馈的重复劳动、被当免费司机。
- 让我在"带队安全"和"内容爆点"之间牺牲前者。

## 6. 如何与我协作(给搭档/团队/未来的我)
> 截至 2026-09-05(示例)· 类型:我的解释,供协作方参考
- 提前给路线和目标,别临时改;我按计划准备最稳。
- 让我讲、别让我写长文档;直接说"这段没懂"最省时间。
- 反馈要具体:"队尾那个新手后来跟上了"比"带得不错"管用。

## 7. 证据库(自愿放入 · 只增不改)
| 日期 | 素材(引用) | 一句话说明 |
|---|---|---|
| 2026-06~08 | 连续 12 个周末免费带同城网友短线,无一人中途放弃 | 行为证据:无人要求、自愿投入 → 指向"带新手"是真实能量区 |
| 2026-08 | 一条"夜爬装备清单"笔记被转给 3 个朋友 | 最小反馈:内容有人觉得有用 |
| (线索)2026-07 | 看到"景区出事"新闻特别愤怒 | 情绪线索(不作事实证据):指向"安全"是他在乎的价值 |

## 8. 维护与修订
- 更新记录:2026-09-05 第一版生成(虚构示例)。
- 纠错记录:(空)
- 下次重审:一个月后,或收到新行为证据时。
- 更新方法:对助手说"更新我的说明书第 X 章";旧版保留可回滚(纯对话模式请把每次旧版自己另存一份)。

# 三、怎么维护(教用户,也写进说明书)

1. **纠错**:发现"这条不像我",直接对助手说,立刻改,记入"维护与修订"章。
2. **更新**:说"更新我的说明书第 X 章",只改那一章;**文件模式保留旧版可回滚;纯对话模式请把每次旧版自己另存**,否则无法回滚。
3. **加证据**:任何时候贴一段自己写过的文字/记录,说明"这是证据,收进证据库";注明它是**行为事实**还是**情绪线索**(情绪峰值只作线索,不作"发生过的事实")。
4. **状态前缀**:每章保持"截至日期 + 类型";有新证据就升格或降格,别让旧结论悄悄变成"事实"。
5. **外置验证**:方向写进"使用目的"后,去做对话外的验证(翻真实记录、问 3 个不太熟的人、两周做最小版本),结果回来前一律当"待验证"。
6. **重审**:一个月或收到明显新证据时,重跑一次证伪关,看方向还站不站得住。
