# 工具与关卡(按需加载,不一次性倒给用户)

> 出处纪律:本文件涉及研究或数字处,一律标注来源;标注不上的,明确写"通俗说法,无权威出处",不以事实口吻出现。

## 5 个误区(第 0 步可用来破题)

| 误区 | 事实(含出处状态) |
|---|---|
| 1. 必须是能坚持一生的事 | 做"现在最想做的"就够了。时代在变,换方向很正常;之前的积累会迁移。(方法观点,源自八木仁平《如何找到想做的事》) |
| 2. 找到时会有"命中注定"的感觉 | 一开始往往只是"好像有点意思",是越做越喜欢。同上。 |
| 3. 必须对别人有益、了不起 | 为自己活也是在帮别人;长期自我牺牲式努力不可持续。注意:坊间流传"自我牺牲式努力最多撑 3 年"的说法查无权威出处,本 skill 不使用该数字。 |
| 4. 想不出来是行动不够,要多试 | 选项过多可能加重决策困难,但这只在特定条件下成立——果酱实验(Iyengar & Lepper, 2000)显示选项过多降低购买率,然而该效应在后续元分析中复制性存疑(Scheibehenne et al., 2010)。本 skill 仅把它当作"选项太多可能加重迷茫"的一种提示,不作铁律。 |
| 5. 想做的事不能成为工作 | 想做的事在你心里,实现手段在社会上——去问、去模仿即可。(八木仁平方法观点;注意对缺钱/缺人脉/行动受限的人,此条是方向而非保证。) |

迷茫的人问"哪条路更划算"(标准在外、随时代变,所以永远摇摆);走自己路的人问"我想怎么做"(标准在内、稳定)。

## 真假价值观(第 1 步用)

- "我想……"= 真价值观;"我应该/不得不……"= 父母、社会塞的假价值观。
- 做法:对每个候选词问"如果没人要求我,我自己想不想?"
- 以他人为中心 → 以自我为中心:对控制不了的词(出名/暴富/被尊敬)连续追问"为什么想要它?→有了之后想做什么?→不靠它能做到吗?",直到挖出能控制的真价值观(常是自由/好奇心/安心)。

## 证伪关(第 4.5 步。本 skill 独有,必过但有护栏)

**为什么要有这道关**:找想做的事的问答流程有个结构性盲区——问的问题绕自我认知,回答来自用户现状,结论就会"证明现状是对的",这是循环论证/现状合理化。证伪关就是拆掉这台"自我安慰机器"。

**必须诚实交代它的边界**:四问的输入仍是用户自述,回答的 AI 又倾向顺着用户——所以**对话内证伪只能筛掉明显的惯性,不能给结论盖章**。真正让假设站稳的是"外置验证"(见下),那才是真值源。

**执行时机**:第 4 步组合出方向之后、生成说明书之前。只用于"方向假设",不是给用户做心理审讯。

### 护栏(先讲,再开跑)
- 开始前征得用户同意:"接下来我会用四问挑战这个方向,目的是省你走错路,不是泼冷水。可以开始吗?"
- 第 4 问(恐惧倒推)可能触发强烈情绪:**先问愿不愿意做;明显低落/脆弱时跳过**,并说明"这问先跳过,等你有能量再做"。
- 任何时候用户不想答,立即停,绝不逼问。
- 全程重申:证伪不过 ≠ 你不行,只是这个假设还没站住。

### 四问(一次一问,等回答)

1. **剥离法**
   "假设把现在已经有的全部清空——你做过的东西、攒下的粉丝、投进去的时间、别人对你的期待——一个完全自由的你,还会选这个方向吗?哪怕它'赚不到钱、看起来没用'。"
   追问:如果答案是"会",让他说清清空后为什么还选;如果犹豫,问"那清空后的你会选什么?"

2. **能量监测**
   "别听嘴说,看账本:过去半年,没人付钱、没人回报时,你仍主动多花时间、甚至废寝忘食去做的是哪类事?"
   把答案和方向对比。对得上 → 加一分;对不上 → 方向可能只是"应该",不是"想"。
   ⚠ 要求用户**当场翻真实记录**(日历/相册/聊天/支付记录),不许凭回忆答——回忆会被现状污染。

3. **拆"该"字**
   "把你正在做的、或这个方向相关的事,一句句过一遍,每句问:这是'我想',还是'我已经在做了/别人期待/投了太多所以觉得该继续'?"
   允许用户诚实承认"有些是该"。把"该"的部分单列出来,不进工作目的。

4. **恐惧倒推(可选,需同意)**
   "你最怕自己变成哪种人?"(先听答案)→ "这个方向,是在帮你成为你想成为的人,还是在帮你回避你怕变成的人?"
   注意:很多人"想做的事"藏在"回避某个版本的自己"背后,这不丢人,把它识别出来就是收获。

### 判定(降级措辞,不给不该有的置信度)
- 四问下来方向没倒,还更清楚 → 标记为"**通过对话内证伪的假设(尚待外部验证)**",进入落地;措辞仍是假设,不是判决。
- 有动摇 → 回第 4 步重新筛方向,或回第 1 步重查工作目的。允许"证伪失败"是正常流程,不是失败。

### 外置验证(过关后必做,可选但强烈建议)
对话内自证永远是温室,让真值源离开对话:
1. **当场翻账本**:真实时间/消费记录(日历、支付、聊天、相册),核对"我确实把时间花在这类事上",而不是凭记忆。
2. **问 3 个不太熟的人**:不要问闺蜜/粉丝/顺着你的人;问会给你难堪答案的人。"如果我去做 X,你会觉得我适合吗?哪里不像?"
3. **两周最小实验**:做最版本的东西(一次咨询、一条内容、一个小产品),看真实世界的反馈(有没有人真的需要/说谢谢/掏钱)。反馈比一切问答都硬。
4. 外置验证的结果回来前,说明书里该方向的措辞一律保持"待验证",不用完成时。

## 回血 vs 抽干(第 2 步用)

- 回血 = 做完更有精神、越做越来劲(可长期投入)。
- 抽干 = 做得好、别人认可,但做完像被掏空(能当责任,别当事业)。
- 关键提醒:**擅长 ≠ 适合长期投入**。用"做完之后的电量"判断,别用"做得顺不顺"判断。
- (说明:此区分受职业倦怠研究启发(Maslach 的倦怠多维模型),此处取其通俗判断,不做学术断言。)

## 重力问题 vs 可设计问题(局部使用时用)

当用户说"我这个情况是不是没救了/只能这样"时,帮他分类:

| 类型 | 含义 | 应对 |
|---|---|---|
| 重力问题 | 无法靠个人行动改变的事实(年龄、市场大环境、别人怎么想) | 接受现实,把力气省下来 |
| 可设计问题 | 能靠行动/选择/实验改变 | 设计小实验去试 |
| 混合问题 | 两样都有 | 拆开,只设计可行动的那部分 |

常见误判:把"暂时没找到方法"当成重力问题,或把"害怕改变"当成重力问题。

## 安全边界与转介(必读,任何时候)

- 本 skill 是自我探索工具,**不是心理治疗或医疗产品**,不诊断、不治疗。
- 若用户出现:持续失眠/食欲骤变、长期无望感或"没意思没价值"、**自伤或自杀念头**、或你判断他处于急性危机——**立即暂停全部走查**,停止追问,并温和转介:
  - 建议联系**当地心理援助/危机热线**(可在网页或官方 App 搜索"心理援助热线"获取你所在地区号码,或问可信任的家人朋友帮忙查);
  - 鼓励他联系**最信任的人**(家人/朋友),不要独自待着;
  - 明确告诉他:寻求专业帮助是勇敢且正常的选择,不是失败。
- 反向推演、恐惧倒推等可能触发强烈情绪的问题,**必须征得同意**,明显低谷时跳过,结束后回到支持性话语与可行动步骤。

## 人格底色探测(结果写进说明书"设计哲学"章)

方法见 questions.md 的"行为证据探针"。核心解读:
- **成就他人型**(更享受助攻/帮人赢/被说有用):能量区 = 帮到具体某个人并被看见;选方向别只看"利他叙事",要真有"收到谢谢"的反馈回路。
- **自我成就型**(更享受自己赢/被看见):能量区 = 有舞台、有反馈、能被不断看见;别被"应该利他"的道德感压掉真实驱动。
- 诚实标注主燃料;识别"嘴说帮人、证据全在证明自己"的矛盾时,温柔点破,不评判。
- ⚠ 底色只是**当前解释**,不是测量结果;写进说明书时标"截至某日 · 基于本次对话的解释",随证据修订。

## 教练自检坑(每次跑完自查)

- 把多个问题一次性砸给用户 → 应一步步来,先答有感觉的。
- 只收集回答、不反射提炼 → 用户觉得在做问卷而非被看见。
- 跳过价值观直接找喜欢/擅长 → 没方向盘,结论站不稳。
- 把控制不了的(出名/暴富)当最终价值观 → 往背后挖。
- 急着说"这就是你的人生方向" → 永远以"假设"措辞;证伪关过了也只是"通过对话内证伪的假设(尚待外部验证)"。
- 说教、灌鸡汤 → 用户带着真实痛苦来,先共情,用他自己的话回应。
- 忽略消遣/逃避型"喜欢" → 诚实区分,并点出背后真正缺的东西。
- 忘了证据层 → 至少各步问一次"有没有你写过的可以贴给我";没有就继续,别卡住。
- 未经同意做恐惧倒推、或在用户低落时硬推 → 违反护栏,禁止。
- 把情绪峰值当"发生过的事实"证据 → 情绪记忆只作线索,不作事实(见 questions.md 证据分级)。
- 把说明书生成当结束 → 还要告诉用户"以后怎么更新、怎么纠错、怎么外置验证"。
